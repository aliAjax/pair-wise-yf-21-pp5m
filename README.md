# hxyfront-62009 地毯修复纹样档案

源提示词编号：2

做一个给手工地毯修复工作室使用的纹样与修复档案前端项目，可以记录地毯产地、年代、结密度、材质、染色类型、破损区域、补线颜色和修复工序。页面需要有纹样局部标记图、修复前后记录、材料色卡、工序进度和按产地筛选的档案列表。

## 返修与二次验收台

在档案基础上扩展了返修与二次验收能力：

- 验收后 7 天内可对单个工序发起返修，需选择工序、填写原因并关联本档案破损区（可在纹样标记图上点选）。
- 工序已有未结返修、超出 7 天窗口、档案已归档、破损区不属于本档案，四种情况整次拒绝，原工序与色卡不变。
- 返修只退回所选工序及后续工序，前面工序保留，已用色卡不返还。
- 二次验收按剩余工序逐道推进，全部完成后核销未结返修并重置验收时间。
- 待返修数与完工率等指标随产地筛选实时更新。

## 代码结构

- `src/domain/reworkRules.ts` — 返修规则（窗口、整次拒绝、退回范围、二次验收）
- `src/data/archiveStore.ts` — 档案存取（种子数据、localStorage 持久化）
- `src/state/useReworkConsole.ts` — 页面状态（筛选、选中档案、返修表单、指标）
